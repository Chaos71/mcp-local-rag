## ADDED Requirements

### Requirement: Автоматическая загрузка .env файла
Система SHALL автоматически искать и загружать файл `.env` из текущей рабочей директории при старте приложения, если он существует.

#### Scenario: Файл .env существует
- **WHEN** приложение запускается и в текущей директории существует файл `.env`
- **THEN** система загружает переменные из файла в `process.env`

#### Scenario: Файл .env не существует
- **WHEN** приложение запускается и в текущей директории нет файла `.env`
- **THEN** система продолжает работу без ошибок (без изменений в поведении)

#### Scenario: Файл .env пустой
- **WHEN** приложение запускается и файл `.env` существует но пуст
- **THEN** система завершает загрузку без изменений в `process.env`

### Requirement: Приоритет внешней среды
Система SHALL НЕ перезаписывать переменные, уже установленные в `process.env` из внешней среды (shell, docker, CI/CD).

#### Scenario: Переменная установлена в shell
- **WHEN** переменная уже существует в `process.env` (например, через `export DB_PATH=./mydb`)
- **THEN** значение из `.env` игнорируется, сохраняется внешнее значение

#### Scenario: Переменная только в .env
- **WHEN** переменная отсутствует в `process.env` но существует в `.env`
- **THEN** значение из `.env` применяется

### Requirement: Поддержка формата .env
Система SHALL корректно парсить стандартный формат `.env`:
- Строки формата `KEY=VALUE` или `KEY="VALUE"`
- Комментарии, начинающиеся с `#`
- Пустые строки (игнорируются)
- Пустое значение (`KEY=` или `KEY=""`)

#### Scenario: Строка с кавычками
- **WHEN** значение в `.env` заключено в двойные кавычки (`KEY="value"`)
- **THEN** кавычки удаляются, сохраняется содержимое (`value`)

#### Scenario: Строка с пробелами в значении
- **WHEN** значение содержит пробелы в кавычках (`KEY="hello world"`)
- **THEN** пробелы сохраняются (`hello world`)

#### Scenario: Комментарий
- **WHEN** строка начинается с `#`
- **THEN** строка игнорируется

#### Scenario: Пустое значение
- **WHEN** строка имеет формат `KEY=` или `KEY=""`
- **THEN** переменной присваивается пустая строка

### Requirement: Обработка ошибок парсинга
Система SHALL корректно обрабатывать ошибки при чтении или парсинге `.env` файла.

#### Scenario: Ошибка чтения файла
- **WHEN** файл `.env` существует но не может быть прочитан (права доступа)
- **THEN** система выводит предупреждение в stderr и продолжает работу

#### Scenario: Некорректный формат строки
- **WHEN** строка в `.env` не соответствует формату `KEY=VALUE` и не является комментарием
- **THEN** строка игнорируется, продолжается парсинг остальных строк

### Requirement: Предупреждения о неизвестных переменных
Система SHALL выводить предупреждения о переменных из `.env.example`, которые не установлены.

#### Scenario: Запуск без конфигурации
- **WHEN** приложение запускается и переменные из `.env.example` не установлены
- **THEN** система выводит список рекомендуемых переменных в stderr

#### Scenario: Частичная конфигурация
- **WHEN** некоторые переменные установлены, но не все
- **THEN** система выводит список только недостающих переменных
