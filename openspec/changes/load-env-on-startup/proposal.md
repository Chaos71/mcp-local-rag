## Why

Пользователям mcp-local-rag необходимо вручную настраивать переменные окружения перед запуском — через shell, systemd, Docker или другие внешние механизмы. Это создаёт барьер входа и увеличивает вероятность ошибок конфигурации. Автоматическая загрузка `.env` файла при старте приложения упростит начальный setup и сделает работу с утилитой более интуитивной.

## What Changes

- При запуске (CLI или MCP сервер) автоматически искать файл `.env` в текущей рабочей директории
- Загружать переменные из `.env` в `process.env`, если они ещё не установлены из внешней среды
- Поддерживать комментарии (`#`) и пустые строки в `.env`
- Не ломать существующие переменные, установленные извне (приоритет внешней среды)
- Добавить опциональную валидацию обязательных переменных с предупреждением в консоль
